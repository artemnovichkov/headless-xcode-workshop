---
description: 6. Create an PR with preview snapshots
---

Open a PR in the existing repo. Commit the preview renders under docs/screenshots and show them in the PR body as a table of thumbnails, one per state. Relative links don't render in PR bodies — use blob URLs pinned to the commit SHA, with ?raw=true.

If an artifact with the renders was published earlier in the session, link it in the PR body next to the table.
